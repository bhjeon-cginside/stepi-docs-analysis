# 우크라이나 전쟁에서 활약하는 스타링크

![](<[우주정책 글로벌이슈리포트-5][2022. 3월] 월간 이슈리포트_images/imageFile4.png>)

미하일로 페도로프 우크라이나 부총리가 러시아의 침공으로 파괴된 통신 문제를 해결하기 위해 스타링크 서비스를 지원해달라고 일론 머스크 스페이스X 최고경영자(CEO)에게 요청. 스타링크가 요청에 화답해 우크라이나에 인터넷 단말기를 보내주고 스타링크 위성을 재배치.

### 스타링크

전 세계에 광대역 인터넷을 제공하도록 설계된 소형 위성 네트워크

### 대형 단일 태양 전지판

우주에서 펼쳐지며 간소화된 셀 설계로 더 쉽고 저렴하게 구축 가능

### 이온 드라이브

크립톤으로 구동되는 추진기는 우주에서 위성을 이동하고 중복 시 우주선을 궤도에서 이탈

### 별 추적기

센서는 인공위성의 방향을 올바르게 유지하는 역할

각 평면 위성의 무게는 260kg에 불과
